# FarsiTV public catalog

This repository contains public FarsiTV catalog data and poster assets. The application source is maintained separately in a private repository.

`catalog.json` and the `posters/` directory contain an initial snapshot generated on 2026-11-23. Playback URLs point to the authorized media host; their presence is not a guarantee that every stream is playable. The snapshot is not yet updated automatically, and the Android app has not yet been switched to this source.

`preview.json` is an earlier incomplete numeric-search snapshot retained for comparison.
